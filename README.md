## 💻 Sobre o projeto

**Bullvest** é um app focado em investimentos, permitindo que usuários acompanhem, simulem ganhos e perdas, e tenham controle financeiro personalizado. A aplicação oferece uma experiência intuitiva e interativa com design moderno usando **React Native** e estilização com **TailwindCSS**. O backend gerencia dados de investimentos, autenticação e histórico financeiro.

---

## 🚀 Funcionalidades

- Cadastro e login de usuário
- Visualização de portfólio e investimentos
- Simulação de ganhos e perdas usando dinheiro virtual
- Histórico de transações e movimentações
- Perfis de investimento: conservador, moderado e agressivo
- Busca e filtro de investimentos
- Controle de entradas e saídas
- Informações do mercado financeiro em tempo real
- Criação de Inteligência artifial para o Aplicativo
- Criação e acompanhamento de metas

## 🛠 Tecnologias

### Frontend

- React Native
- TailwindCSS
- TypeScript

- Axios (para requisições HTTP)

### Backend

- Node.js
- Fastify
- TypeScript
- Banco de dados PostgreSQL
